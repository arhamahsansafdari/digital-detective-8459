## Python Programs

### Hello World

### Number Converter

From the repository root:

```bash
python3 mission-05-numbers-data/number_converter.py
```

Or from its mission folder:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

The number converter accepts a decimal integer and displays its binary and hexadecimal representations.

Example:

```text
Enter a positive decimal number: 13
Decimal: 13
Binary: 0b1101
Hexadecimal: 0xd
```

## My Learning

Through this assignment, I learned how computer hardware, software and operating systems work together.

I practised Terminal commands for navigating directories and managing files.

I learned basic Python programming and how numbers are represented using binary, decimal and hexadecimal systems.

I also explored Git version control, including staging, committing, branches and Pull Requests.

Finally, I studied how computer networks use DNS, routers and communication protocols to exchange information.
