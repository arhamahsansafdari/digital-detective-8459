## 3. Commands / tools used

- **VS Code:** Used to open, organise, and edit project files.
- **Terminal:** Used to execute commands on macOS.
- **cd:** Changes the current working directory.
- **pwd:** Displays the current working directory.
- **mkdir:** Creates new directories.
- **touch:** Creates empty files if they do not already exist.
- **python3 --version:** Displays the installed Python 3 version.
- **git --version:** Displays the installed Git version.
- **git init:** Initialises a local Git repository.
- **git branch -M main:** Sets the current branch name to main.
- **git remote add origin:** Connects the local repository to the remote GitHub repository.
- **git status:** Displays the state of files and changes in the repository.
- **git add:** Stages selected files for a commit.
- **git commit:** Records a snapshot of staged changes.
- **git push:** Uploads local commits to GitHub.
- **git log --oneline:** Displays a shortened history of commits.

## 4. My understanding

A Git repository is a project folder where Git keeps track of changes made to files over time. GitHub is an online platform where repositories can be stored and shared.

Organising the assignment into separate mission folders makes it easier to find files, understand the purpose of each task, and maintain a clear project structure.

I also learned that Git allows us to save different versions of our work using commits. By pushing these commits to GitHub, we can make our project available online and maintain a record of our progress.
